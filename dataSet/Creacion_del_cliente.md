## Gestión de Clientes (Panel Distribuidor)

El módulo de **Cuentas de Cliente** permite a los distribuidores administrar su cartera de clientes, crear nuevas cuentas y supervisar el acceso de cada cliente a la plataforma.

Desde este módulo se centraliza la gestión administrativa de clientes y su habilitación dentro del sistema.

---

## Creación de una nueva cuenta de cliente

Para registrar a un nuevo cliente en el sistema, siga estos pasos:

1. Diríjase a la sección **Cuentas de Cliente** desde el panel del distribuidor.
2. Presione el botón **Agregar Cliente** para abrir el formulario de registro.
3. Complete la información solicitada para la nueva cuenta.

Una vez guardada la información, la cuenta del cliente quedará registrada en el sistema.

---

## Activación y credenciales

Es fundamental ingresar un **correo electrónico válido**, ya que el proceso de activación funciona de la siguiente manera:

* **Envío automático**: Al finalizar la creación del cliente, el sistema envía automáticamente un correo electrónico a la dirección registrada.
* **Contraseña temporal**: El correo contiene una contraseña provisional generada por el sistema para que el cliente pueda realizar su primer inicio de sesión.
* **Seguridad**: En el primer acceso, el sistema solicitará de forma obligatoria el cambio de contraseña.

Este flujo garantiza que cada cliente tenga credenciales únicas y seguras desde su primer acceso a la plataforma.
